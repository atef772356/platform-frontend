# NexaLearn Frontend
واجهة React + TypeScript احترافية ومتكاملة مع مشروع Enterprise LMS API.

## التشغيل
1. شغّل الباك إند على المنفذ 3000.
2. انسخ `.env.example` إلى `.env`.
3. نفّذ `npm install`.
4. نفّذ `npm run dev`.
5. افتح `http://localhost:5173`.

يستخدم Vite proxy لإرسال `/api` إلى `http://localhost:3000`، لذلك لا تحتاج إلى CORS أثناء التطوير.

## الحسابات والأدوار
التسجيل من الواجهة ينشئ STUDENT. لإنشاء INSTRUCTOR أو ADMIN، عدّل الدور من Prisma Studio أو أضف seed في الباك إند.

## الصفحات
- Landing page
- تسجيل الدخول وإنشاء الحساب
- كتالوج الدورات وتفاصيل الدورة
- لوحة تحكم متجاوبة حسب الدور
- استوديو المدرّس لإنشاء دورة ووحدة ودرس
- مركز الطالب لإكمال الدروس والاختبارات والواجبات والشهادات
